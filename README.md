# SokuSai - 息災

「推しの休止期間中や活動終了後などに元気で生きてほしいという気持ちを行動に移したい」「表舞台に出ていないときでも誰かが自分のことを想っていてくれているということを実感できるようにしたい」という想いで構想した企画案です。現在、フロントエンドのみの実装となります。

---

### ファン側のユーザー体験（UX/機能）

推しの健康を願って、**紙飛行機を折り、飛ばす**というユーザー体験を実現しています。<br>
メッセージ機能を持たせないことで、推しの負担にならないような設計としています。<br>

* **利用のタイミング**: 起床した後にアクセスする想定です。
* **宛先設定**: 推しのYoutubeアカウントをニックネーム登録しておき、アクセス時に宛名として入力。<br>
※ YouTubeアカウントは「YouTubeアカウントURL」の入力➔バックエンド側でURLから自動的にチャンネルIDを抽出・取得してデータベースに登録する、という仕様です。
* **紙飛行機を折る**: インタラクティブな動作を通じて自然な流れで紙飛行機ができていきます。
* **紙飛行機を飛ばす**: 紙飛行機を飛ばす舞台として、湖面が鏡のようになっているウユニ塩湖のような場所を設定します。
* **用紙の受け取り**: 起床時刻前（朝3時）に紙飛行機の用紙が毎日1枚ずつユーザーに届きます。
* **記念日の登録機能**: 登録した記念日には、普段の折り紙の代わりに「淡い水色の特別な折り紙」を使用して紙飛行機にできます。
* **スタンプラリー機能**: デフォルトのスタンプはシンプルな二重丸です。
* **スタンプカードのアップロード機能**: スタンプカードを自分のアップロードした画像に変更することができます。スタンプを押す場所となる要素との重なり具合をプレビューできる機能もあります。

---

### 推し側のユーザー体験（UX/機能）

* **自動ダッシュボード**: 推し本人が自身のYoutubeアカウントでログインすると、自動的に自分宛ての紙飛行機が集まるダッシュボードへ遷移する仕様です。
* **蓄積の可視化**: ダッシュボードの画面上に「今日は〇〇機の紙飛行機が届いています」というカウンターを設置します。
* **想いの受け取り**: 届いた紙飛行機をクリックして開くと、「今日も（ファンの名前）さんが紙飛行機を飛ばしてくれました」というテキストが表示されます。
